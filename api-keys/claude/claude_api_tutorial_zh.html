如何獲取 Claude API 金鑰

按照此逐步指南獲取您的 Anthropic Claude API 金鑰，開始使用人工智能進行構建

開始使用 Claude API

此指南將引導您完成建立 API 金鑰的過程，以存取 Claude 模型

1

前往 Anthropic 主控台

導覽到 Anthropic 主控台，您可以在該位置管理 API 金鑰和帳戶設定。

https://console.anthropic.com

Anthropic API 主控台

造訪：https://console.anthropic.com

這是存取您的 API 金鑰和帳戶的官方平台。

💡 提示：將此頁面加入書籤以便今後快速存取。
2

建立帳戶或登入

如果您沒有 Anthropic 帳戶，請建立一個帳戶。如果您已經有帳戶，只需使用您的認證資訊登入。

📧 您可以透過以下方式註冊：
  • 電子郵件地址
  • Google 帳戶
  • GitHub 帳戶

在註冊期間，您需要提供電子郵件並建立密碼，或透過您偏好的 OAuth 提供者進行身份驗證。

3

導覽至 API 金鑰部分

登入後，在主控台儀表板中找到 API 金鑰部分。

console.anthropic.com / dashboard

導覽步驟：

1. 按一下您的帳戶圖示或功能表（右上方）

2. 從下拉式選單中選擇「API 金鑰」或「金鑰」

3. 您會看到現有金鑰的清單（如果有的話）

4

建立新的 API 金鑰

按一下按鈕以建立新的 API 金鑰並為其提供描述性名稱。

✏️ 命名最佳實務：
  • 使用描述性名稱（例如「production-app」、「testing-env」）
  • 包含用途或環境
  • 避免使用通用名稱，如「Key1」或「Test」
create_api_key_dialog

建立 API 金鑰

金鑰名稱：my-production-api

提供名稱後，系統會為您產生唯一的金鑰。

5

複製並儲存您的 API 金鑰

複製您的 API 金鑰並將其安全地儲存。關閉此對話方塊後，您將無法再看到它。

🔑 您的 API 金鑰格式：
sk-ant-api...

所有 Claude API 金鑰都以 sk-ant- 前綴開頭，後面跟著一長串英數字字符。

帳單設定

若要使用您的 API 金鑰並存取 Claude 模型，您需要設定帳單資訊。

  • 信用額度制系統：您根據 token 消耗量為您使用的內容付費
  • 設定帳單限額：使用預算上限控制您的支出
  • 每月發票：在儀表板中追蹤您的使用情況和成本
  • 無設定費用：從小規模開始，視需要擴展

定價因模型而異。Claude Opus 功能最強大（成本最高），而 Haiku 速度最快且最實惠。如需目前費率，請查看 Anthropic 定價頁面。

⚠️ 安全警告

永遠不要公開分享您的 API 金鑰或將其提交至版本控制。將其視為密碼。

  • 儲存在環境變數中
  • 使用秘密管理工具
  • 定期輪換金鑰
  • 刪除未使用的金鑰

💡 可用模型

取得 API 金鑰後，您可以使用這些 Claude 模型：

  • Claude Opus：最有能力
  • Claude Sonnet：平衡的
  • Claude Haiku：快速且實惠
