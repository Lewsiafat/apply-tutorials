1

註冊 Meta 開發者帳號

開啟 https://developers.facebook.com,用 Facebook 帳號登入,首次使用點右上角「開始使用」(Get Started),同意開發者條款、驗證電子郵件/手機即完成註冊(已是開發者可跳過本步)。完成後點上方 我的應用程式 進入應用程式列表。

主控板會出現「應用程式自訂和要求」清單,點第一項 自訂存取 Threads API 的使用案例(或左側 使用案例 → 自訂),進入「權限和功能」頁。

  1. threads_basic 建 App 時已自動加入(所有 Threads API 呼叫的基礎)。
  2. 找到 threads_content_publish 按 ＋ 新增 —— 這是「發文」權限。
  3. 找到 threads_manage_replies 按 ＋ 新增 —— 這是「回文」權限。
  4. 建議一併加入 threads_read_replies,才能讀取回覆串。
「可供測試」是什麼意思?開發模式下,這些權限對「Threads 測試人員」立即生效,不必送審。要開放給任何 Threads 用戶授權,才需要走「應用程式審查」並提供示範影片等資料。

  1. Threads 應用程式編號 / 密鑰:寫程式走 OAuth 流程時的 client_id / client_secret。密鑰請妥善保管,勿放進前端或公開 repo。
  2. 重新導向回呼網址:OAuth 授權完成後跳轉的網址,必須是 HTTPS(實測 localhost 會被拒絕)。輸入網址後要按 Enter 讓它變成標籤(chip)再按「儲存」,否則會出現「無法儲存表單」。

5

新增 Threads 測試人員並產生存取權杖

  1. 在「用戶權杖產生器」按 新增或移除 Threads 測試人員,會開啟「應用程式角色」頁。
  2. 按 新增用戶 → 選 Threads 測試人員 → 輸入你的 Threads 用戶名稱(@handle)→ 送出邀請。
  3. 用手機打開 Threads App:設定 → 帳號 → 網站權限 → 邀請,接受測試邀請。
  4. 回到「設定」頁的用戶權杖產生器,你的帳號旁會出現 產生存取權杖 按鈕,點它並登入 Threads 授權,即可複製一組長效存取權杖(60 天有效)。
權杖 = 密碼存取權杖能直接以你的身分發文。請存在環境變數或秘密管理服務,別寫死在程式碼裡。60 天到期前可用 refresh 端點換新。
6

用 API 發文

Threads 發文是兩段式:先建立「媒體容器」,再「發佈」容器。端點是 https://graph.threads.net。

# 1) 建立文字貼文容器
curl -X POST "https://graph.threads.net/v1.0/me/threads" \
  -d "media_type=TEXT" \
  -d "text=我的第一篇 Threads API 貼文!" \
  -d "access_token=你的存取權杖"
# 回傳 {"id": "17888..."}  ← 這是容器 ID

# 2) 發佈容器(建議等 30 秒讓伺服器處理完)
curl -X POST "https://graph.threads.net/v1.0/me/threads_publish" \
  -d "creation_id=17888..." \
  -d "access_token=你的存取權杖"
# 回傳 {"id": "18027..."}  ← 這是正式貼文 ID

Python 版:

import requests, time, os

TOKEN = os.environ["THREADS_TOKEN"]
BASE  = "https://graph.threads.net/v1.0"

# 建立容器
r = requests.post(f"{BASE}/me/threads", data={
    "media_type": "TEXT",
    "text": "用 Python 發的 Threads 貼文 🎉",
    "access_token": TOKEN,
}).json()
container_id = r["id"]

time.sleep(30)  # 官方建議等容器處理完再發佈

# 發佈
r = requests.post(f"{BASE}/me/threads_publish", data={
    "creation_id": container_id,
    "access_token": TOKEN,
}).json()
print("貼文 ID:", r["id"])
發圖片/影片?把 media_type 改為 IMAGE 並加 image_url=https://…(必須是公開可存取的網址);影片用 VIDEO + video_url。多圖輪播要先建立多個子容器再組成 CAROUSEL 容器。
7

用 API 回覆串文

回覆(回文)同樣是兩段式,只是在建立容器時多帶一個 reply_to_id 參數(需要 threads_manage_replies 權限):

# 1) 建立「回覆」容器:reply_to_id = 要回覆的貼文 ID
curl -X POST "https://graph.threads.net/v1.0/me/threads" \
  -d "media_type=TEXT" \
  -d "text=這是用 API 發出的回覆!" \
  -d "reply_to_id=18027..." \
  -d "access_token=你的存取權杖"

# 2) 一樣用 threads_publish 發佈
curl -X POST "https://graph.threads.net/v1.0/me/threads_publish" \
  -d "creation_id=回覆容器ID" \
  -d "access_token=你的存取權杖"

常用的回覆管理端點(threads_read_replies / threads_manage_replies):

8

常見問題

Q1:「重新導向回呼網址」一直存不進去?

兩個常見原因:(1) 網址不是 HTTPS 或用了 localhost —— 換成正式網域;(2) 輸入後沒按 Enter 把網址變成標籤(chip)就按儲存 —— 實測必須先 Enter 再儲存。

Q2:權杖產生器沒有「產生存取權杖」按鈕?

對方(或你自己)還沒在 Threads App 裡接受測試人員邀請,或 Threads 帳號不是公開帳號。

Q3:發文回傳權限錯誤 (#10 或 OAuthException)?

檢查三件事:權杖是否過期(60 天)、該權限是否已加入使用案例(步驟 3)、授權當下是否有勾選對應 scope(threads_content_publish 等)。

Q4:一天可以發多少篇?

目前官方限制約每 24 小時 250 篇貼文、1,000 則回覆。可用 GET /me/threads_publishing_limit 查詢已用額度。

Q5:要給其他人使用我的服務?

需在「應用程式審查」中為 threads_basic、threads_content_publish 等權限申請「進階存取」,提交使用說明與示範影片,審核通過後任何 Threads 用戶都能授權你的 App。
