如何取得
Google Gemini API Key

步驟教學 — 取得 Gemini 等 Google AI 模型的 API 存取權

1

前往 Google AI Studio

在瀏覽器中開啟 Google AI Studio，使用你的 Google 帳號登入。

https://aistudio.google.com
💎

Google AI Studio

用 Google 帳號登入
如果還沒有 Google 帳號，可以免費建立一個。可以使用 Gmail、Google Workspace 或其他 Google 帳號。
2

用 Google 帳號登入

點 「用 Google 帳號登入」，然後輸入你的 Google 帳密登入。系統可能會要求你授予 Google AI Studio 存取權。

accounts.google.com/signin

登入你的 Google 帳號

your.email@gmail.com
••••••••
下一步
3

進入 API Keys 部分

登入後，點選左側選單或個人資料圖示，找到 「取得 API Key」 或進入 API Keys 區段。

aistudio.google.com/app/apikey
Chat
Notebooks
API keys
Settings

API Keys

你的 API 金鑰列在下方。

+ 建立 API Key
4

建立新的 API Key

點 「建立 API Key」。系統會提示你選擇一個 Google Cloud 專案或建立新專案。選擇或建立專案，然後確認建立。

aistudio.google.com/app/apikey

建立新的 API Key

我的 Gemini 專案

選擇現有專案或建立新專案

在專案中建立 API Key
Google Cloud 專案免費建立。你可以稍後在 Google Cloud Console 管理專案。
5

複製並儲存你的 API Key

新的 API Key 會顯示出來。請立刻複製並存放到安全的地方。你將使用此 Key 來驗證對 Gemini API 的請求。

AIzaSy_1234567890ABCDEfGhIjKlMnOpQrStUvWxYz
🎉

API Key 建立成功！

現在你可以用這個 Key 來呼叫 Gemini API。Google Gemini 提供寬裕的免費層級，適合測試和開發。

務必保護好你的 API Key，切勿公開分享。如果不小心洩露，可以刪除它並建立一個新的。建議存在密碼管理器或環境變數中。
Google Gemini 提供免費層級，配額寬裕。你可以在 Google Cloud Console 監測使用量並設定配額上限，避免意外費用。

祝你開發 Google Gemini 順利！💎
