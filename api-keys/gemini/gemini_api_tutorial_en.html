Google Gemini API Key

A step-by-step visual guide to access Gemini and other Google AI models

1

Go to Google AI Studio

Visit Google AI Studio in your browser and sign in with your Google account.

https://aistudio.google.com

If you don't have a Google account, you can create one for free. You can use an existing Gmail, Google Workspace, or other Google account.
2

Sign in with Your Google Account

Click "Sign in with Google" and log in with your Google credentials. You may need to grant Google AI Studio access to your account.

Navigate to API Keys Section

Create a New API Key

Click "Create API key". You'll be prompted to select a Google Cloud project or create a new one. Choose or create a project, then confirm the creation.

5

Copy & Save Your API Key

Your new API key will be displayed. Copy it immediately and store it somewhere safe. You'll use this key to authenticate requests to the Gemini API.

API Key Created!

You can now use this key to call the Gemini API. Google Gemini has a generous free tier for testing and development.

Keep your API key secure and never share it publicly. If you accidentally expose it, you can delete and create a new one. Store it in a password manager or environment variable.
Google Gemini has a free tier with generous quotas for API usage. You can monitor your usage and set quotas in the Google Cloud Console to avoid unexpected charges.

Happy building with Google Gemini! 💎
