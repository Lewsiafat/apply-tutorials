歡迎來到 OpenRouter

一個 API 密鑰存取 200+ 個模型

開始使用
什麼是 OpenRouter？一個 API 聚合平台，統一存取 GPT-4、Claude 3、Gemini、Llama、Mistral 和許多其他模型。按使用量付費，使用信用額系統。
2

註冊或登入

點擊「開始使用」或登入。您可以使用 Google 帳戶、GitHub 帳戶，或直接建立 OpenRouter 帳戶。

https://openrouter.ai/auth/signin

登入 OpenRouter

使用 Google 登入
或
使用 GitHub 登入
OpenRouter 支援使用 Google 和 GitHub 進行單一登入 (SSO)，快速且安全。
3

前往密鑰頁面

登入後，導航至openrouter.ai/keys，或點擊您的個人資料選單並從設定中選擇「API 密鑰」。

https://openrouter.ai/keys

複製並保存您的密鑰

API 密鑰已建立！

您的密鑰已準備好使用。立即開始對任何 200+ 模型進行 API 呼叫。

切勿公開分享您的 API 密鑰。如果洩露，立即刪除它並建立新的。將其視為密碼對待。
OpenRouter 使用信用額計費系統。通過帳單頁面添加信用額，只需為您使用的部分付費。費率具有競爭力，按模型而異。

免費層和試用

OpenRouter 提供免費層模型，包括 Llama 2、Mistral 等。您可以在不添加付款方式的情況下測試 API。當您準備好時，為 GPT-4 和 Claude 3 等高級模型添加信用額。
