## 🚀 Usage

Clone the repo and open any `.html` file in your browser:

```bash
git clone https://github.com/Lewsiafat/apply-tutorials.git
cd apply-tutorials
open bots/discord/discord_bot_tutorial_zh.html   # macOS
# or
xdg-open bots/discord/discord_bot_tutorial_zh.html  # Linux
```
